# Contributing

Bug reports, compatibility results, documentation improvements, and focused pull
requests are welcome. Search existing issues before opening a new one.

For bugs, include the app version, Android version, Apple TV model and tvOS
version, reproduction steps, and expected versus actual behavior. Remove device
names, addresses, serial numbers, pairing codes, credentials, and entered text
from logs and screenshots.

## Development

Follow the build instructions in [README](README.md). Keep UI and Android
lifecycle work in `app`, and transport, pairing, and codecs in
`protocol-appletv`. Add regression coverage for behavior changes.

```bash
./gradlew :app:testDebugUnitTest :protocol-appletv:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Use an Android 16 emulator for instrumentation tests. Test runners may reset
application data; do not target a personal phone with saved pairing data.

```bash
ANDROID_SERIAL=emulator-5554 ./gradlew :app:connectedDebugAndroidTest
```

Screenshots are generated by `PublicScreenshotsTest` using fictional device
data and the actual Compose UI. They demonstrate layout, not live TV control.

Never commit SDK paths, signing keys, pairing data, or private diagnostics.
